# Copy ONE block like the one below into  featured.md  to promote a paper on the
# Publications page. Cards appear in the order they are listed in featured.md.
#
# The "## Heading" text is used (case-insensitive) to find the matching citation in
# resume.md, so the full citation is pulled in automatically — never retyped here.
#
# Fields (all optional; omit any you don't need):
#   match    override the substring used to match the resume.md citation
#            (use this when the heading text differs from the citation wording)
#   image    teaser image path under media/, e.g. media/my-paper.png
#            The card renders text-only until that file exists, so it is safe to add early.
#   venue    short label shown in accent color, e.g. CVPR 2026 / IEEE RA-L 2025
#   blurb    one-line description of the work
#   <Label>  any other "Label: url" line becomes a link button. Common labels:
#            PDF, Code, Project, Video, Dataset, arXiv, Slides
